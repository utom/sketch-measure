# Sketch Measure Modern - 安装指南

## 🚀 快速安装

### 方法 1：直接安装插件 (推荐)

1. 下载 `sketch-measure-modern.sketchplugin` 文件
2. 双击插件文件，Sketch 会自动安装
3. 在 Sketch 中即可看到 "Sketch Measure Modern" 菜单

### 方法 2：手动安装

1. 将 `sketch-measure-modern.sketchplugin` 复制到插件目录：
   ```
   ~/Library/Application Support/com.bohemiancoding.sketch3/Plugins/
   ```
2. 重启 Sketch

## ✅ 验证安装

安装成功后，您应该能在以下位置看到插件：

1. **菜单栏**: `Plugins` → `Sketch Measure Modern`
2. **工具栏**: 各种测量工具按钮
3. **快捷键**: 
   - `Ctrl + Shift + B` - 工具栏
   - `Ctrl + Shift + 1` - 标记覆盖层
   - `Ctrl + Shift + 2` - 标记尺寸
   - 等等...

## 🔧 系统要求

- **Sketch**: 84.0 或更高版本
- **macOS**: Sonoma (14.0) 或更高版本
- **架构**: 支持 Intel 和 Apple Silicon (M1/M2/M3)

## 🎯 首次使用

1. 打开任意 Sketch 文档
2. 选择一个图层
3. 按 `Ctrl + Shift + 2` 标记尺寸
4. 按 `Ctrl + Shift + E` 导出规范

## 📝 功能列表

- ✅ **标记覆盖层** - 高亮显示图层
- ✅ **标记尺寸** - 显示宽度和高度  
- ✅ **标记间距** - 测量图层间距
- ✅ **标记属性** - 显示样式信息
- ✅ **添加注释** - 自定义文本注释
- ✅ **导出规范** - 生成 HTML 文档
- ✅ **颜色管理** - 分析设计颜色
- ✅ **设置导出** - 批量导出配置

## 🐛 故障排除

### 插件无法显示
- 确认 Sketch 版本 >= 84.0
- 重启 Sketch 应用
- 检查插件是否在正确目录

### 快捷键不工作
- 检查是否与其他插件冲突
- 在系统偏好设置中自定义快捷键

### 导出失败
- 确认有写入权限
- 选择其他导出位置
- 检查磁盘空间
